# App Multimedia

Aplicación desarrollada en Flutter para el Taller 01 de Ingeniería Multimedia.

**Autor:** Sergio Luis Durango Banquez

## Funcionalidades

- Navegación mediante BottomNavigationBar.
- Visualización de imágenes con GridView.builder.
- Reproducción de video utilizando video_player.
- Navegación web integrada mediante webview_flutter.
- Conservación del estado de las vistas usando IndexedStack.
- Estructura modular para facilitar el mantenimiento y la escalabilidad.

## Tecnologías Utilizadas

- Flutter
- Dart
- video_player
- webview_flutter

## Estructura del Proyecto

```text
lib/
├── main.dart
└── screens/
    ├── main_navigator.dart
    ├── image_screen.dart
    ├── video_screen.dart
    └── web_screen.dart
```

## Instalación y Ejecución

```bash
flutter pub get
flutter run
```
